# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on investigating the basic components of cloud infrastructure using a Linux environment provided through KillerCoda. The activity involves examining server information, identifying compute, storage, networking, and operating system resources, comparing major cloud providers, and creating a simple cloud infrastructure diagram.

## Objectives

- Investigate the hardware and software resources of a Linux cloud environment.
- Identify compute, storage, networking, and operating system components.
- Compare cloud services offered by AWS, Microsoft Azure, and Google Cloud Platform.
- Create a simple cloud infrastructure diagram.
- Document technical findings using Markdown and GitHub.

## Cloud Infrastructure Components

The main cloud infrastructure components identified in this activity are:

- **Compute** – Provides processing power for running applications and services.
- **Storage** – Stores the operating system, files, and other data.
- **Networking** – Allows communication between users, servers, and cloud resources.
- **Operating System** – Ubuntu Linux manages the server's hardware and software resources.
