# Reflection

Through this activity, I learned about the basic components that make up a cloud infrastructure. By using the KillerCoda Ubuntu environment, I was able to examine the operating system, CPU, memory, storage, hostname, and network information of a Linux server. This gave me a better understanding of how a cloud server works and how different resources are used to support applications and services.

I also learned that compute, storage, networking, and the operating system work together to provide a complete cloud environment. Compute resources provide the processing power needed to run applications, while storage is used to save the operating system, files, and other important data. Networking allows users and systems to communicate with each other, while the operating system manages the hardware and software resources of the server.

Another important part of the activity was comparing AWS, Microsoft Azure, and Google Cloud Platform. This helped me understand that different cloud providers offer similar services for computing, storage, networking, and identity and access management. However, each provider has its own strengths, services, and advantages depending on the needs of the user or organization.

Creating the cloud architecture diagram also helped me visualize how the different components of a cloud environment are connected. I learned how a user can access cloud resources through the internet and a cloud network to reach compute and storage resources.

Overall, this activity helped me better understand the basic concepts of cloud computing. It also gave me hands-on experience using a Linux cloud environment and documenting the information I collected. I now have a clearer understanding of how cloud infrastructure resources work together to provide reliable and accessible services.
