# Reflection

Through this activity, I learned about the basic components that make up a cloud infrastructure. By using the KillerCoda Ubuntu environment, I was able to examine the operating system, CPU, memory, storage, hostname, and network information of a Linux server.

I also learned that compute, storage, networking, and the operating system work together to provide a complete cloud environment. The activity helped me understand how these resources are connected and why each component is important in running applications and services in the cloud.

Comparing AWS, Microsoft Azure, and Google Cloud Platform also gave me a better understanding of the different cloud providers and the services they offer. Creating the cloud architecture diagram helped me visualize how a user can connect through the internet and cloud network to access compute and storage resources.

Overall, this activity helped me better understand the basic concepts of cloud computing and how cloud infrastructure resources work together.
